# Animal-Adoption-App
A full-stack animal adoption platform built with React, ASP.NET Core Web API, and MSSQL. This Project aims to connect adopters with pets through a modern, scalable, and user-friendly system.

EvcilHayvanSahiplendirme: AI Destekli Evcil Hayvan Sahiplendirme Platformu EvcilHayvanSahiplendirme:, sokaktaki ve barınaklardaki dostlarımızın kalıcı yuvalarına kavuşmasını sağlayan, modern teknolojiler ve yapay zeka ile güçlendirilmiş bir sahiplendirme ekosistemidir.

Öne Çıkan Özellikler Projemiz, standart bir sahiplendirme sitesinden fazlasını sunmak için iki ana AI motoru üzerine inşa edilmiştir:

Akıllı Uyumluluk Analizi Kullanıcıların yaşam tarzı, ev koşulları ve beklentileri ile hayvanların karakter özelliklerini (enerji seviyesi, çocuklarla uyum, tüy dökme vb.) eşleştiren gelişmiş bir algoritma.
Nasıl Çalışır? Kullanıcı bir anket doldurur; AI, veri setindeki yüzlerce ilan arasından en uygun dostlarımızı önerir.

Görüntü İşleme ile Otomatik Hayvan Tespiti İlan verme sürecini hızlandırmak için geliştirilen Computer Vision (Bilgisayarlı Görü) modülü.
Yetenekler: Yüklenen fotoğraftan hayvanın türünü (Kedi, Köpek, Kuş vb.), cinsini otomatik olarak tespit eder. Alan,Teknoloji Frontend,React.js / Next.js & Tailwind CSS Backend,Node.js (Express) / Python (FastAPI) Veritabanı,MySQL Yapay Zeka,TensorFlow / PyTorch (CNN Modelleri) NLP,OpenAI API veya HuggingFace (Karakter Analizi için)
